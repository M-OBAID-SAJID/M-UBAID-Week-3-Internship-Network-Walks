## 📌 Project Overview

As part of my **Cybersecurity & Ethical Hacking Internship at Network Walks**, I completed Week 3, Project Module 1,2  focusing on password security and password recovery.

In this practical task, I explored PDF password protection, hash extraction, and password recovery using different cybersecurity tools.

## 🎯 Objectives

- Understand password hashing and PDF password protection.
- Extract password hashes from protected PDF files.
- Learn to use John the Ripper.
- Explore Network Walks Hash Cracker.
- Explore Network Walks Password Cracker.
- Perform password recovery testing using wordlists.
- Analyze and document password recovery results.

## 🛠️ Tools & Technologies

| Tool | Purpose |
|---|---|
| Kali Linux | Testing environment |
| John the Ripper (JTR) | Password recovery |
| Network Walks Hash Cracker | Hash analysis and cracking practice |
| Network Walks Password Cracker | Password recovery practice |

| Windows | Hash extraction and file management |

## ⚙️ Practical Implementation

### Step 1 – PDF Hash Extraction
- Selected the provided password-protected PDF samples.
- Extracted their password hashes.
- Saved the extracted hashes into separate text files.

### Step 2 – Network Walks Tools
- Explored Network Walks Hash Cracker.
- Practiced hash analysis and recovery.
- Used Network Walks Password Cracker for password recovery exercises.

### Step 3 – John the Ripper on Kali Linux
- Checked the John the Ripper installation.
- Verified PDF hash format support.
- Prepared the RockYou wordlist.
- Loaded extracted hashes into John the Ripper.
- Performed wordlist-based password recovery tests.

### Step 4 – Result Verification
- Reviewed password recovery results.
- Identified recovered and unrecovered hashes.
- Documented the practical outcomes.


## 📚 Learning Outcomes

- Understood PDF password hash extraction.
- Explored different hash and password recovery tools.
- Practiced command-line operations in Kali Linux.
- Learned about wordlist-based password testing.
- Understood the importance of strong password policies.
